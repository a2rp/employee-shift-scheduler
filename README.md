# Shiftline - Employee Shift Scheduler

Shiftline is a weekly workforce planner for assigning employee shifts and keeping store coverage visible. Browse a roster by week, adjust shift hours, review team workloads, and find open coverage at a glance.

**Live scheduler:** [https://a2rp.github.io/employee-shift-scheduler/](https://a2rp.github.io/employee-shift-scheduler/)

## Features

- Review a seven-day employee roster with local dates and shift hours.
- Add, edit, and remove shifts for a team member and location.
- Prevent overlapping shifts for the same employee.
- Copy the previous week's shifts into open employee and day slots.
- Search by employee, role, team, or location.
- Filter the roster by department and work location.
- Track daily coverage gaps and compare weekly hours with each employee's target.
- Save schedule changes in browser storage on the current device.
- Use the roster on desktop, tablet, and mobile screens.

## Run locally

```sh
npm install
npm run dev
```

## Checks and deployment

```sh
npm run lint
npm run build
npm run deploy
```

`npm run deploy` builds the app and publishes the `dist` folder to the `gh-pages` branch.

**Deployed scheduler:** [https://a2rp.github.io/employee-shift-scheduler/](https://a2rp.github.io/employee-shift-scheduler/)
